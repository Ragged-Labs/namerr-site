What is Namerr?

Namerr is a self-hosted movie and television library organiser. It analyses media files, proposes consistent paths and helps you review each decision before approved changes are applied. It is a companion to your media servers and library managers, not a replacement for them.

Product status

Namerr 2.0.48 is the development baseline used for this website's product information. The public distribution, new guided-review redesign, AI, Jellyfin and extended media types are separate planned work. They must not be treated as shipped features.

Installation status

Public installation is being prepared. Namerr is designed for Docker and Unraid, with a web interface accessible on the configured local port. The current existing-install defaults use port 8129 and separate persistent appdata and TV/movie mounts; details are subject to the official public installer guide.

  1. Wait for a verified public distribution package on the Download page.
  2. Before installing, make a reliable backup of your library and application configuration.
  3. Configure media paths and persistent appdata deliberately; do not mount the wrong directory.
  4. Keep the web interface restricted to your trusted network unless you have properly secured access.

Do not replace existing Unraid paths or container identity just because the public website uses the Namerr brand.

Your first review

  1. Select a supported Movies or TV library.
  2. Check your current profile and naming choices.
  3. Run a scan and inspect proposed actions.
  4. Resolve any held matches, specials or ambiguous assets.
  5. Select only the changes you want, then apply.
  6. Review the operation report; use the built-in recovery workflow if anything needs attention.

Scanning and previewing are separate from moving files. Changes are not automatically approved simply because a file looks like a match.

Naming profiles

Naming profiles control the way paths are presented. Depending on the inspected media and selected rules, they can include title, year, resolution, source, codec, bit depth, audio codec, channel count and container. Unknown properties are not invented by the application.

Optional metadata connections

The existing product provides optional connection settings for Sonarr, Radarr, Plex, Emby and TMDB. These can support identity research, file-to-library comparison and selected integration workflows. Availability of specific remote actions varies by provider configuration.

Jellyfin and AI adapters for Ollama, OpenAI, Claude and Grok are on the roadmap, not the current public feature set. All future model-assisted changes will require their own reviewed execution and privacy controls.

Undo and recovery

Namerr records operations so interrupted or problematic changes can be investigated against the original work. Depending on the completed operation and verified file state, recovery can include continuing recorded moves, restoring original paths or confirming completed outcomes.

Recovery is deliberately conservative. If paths are missing, altered or occupied, the action can remain blocked rather than guessing. Permanent deletion cannot be reversed by an Undo button.

Safety essentials

  • Keep a separate, tested backup of both media and application data.
  • Preview changes and verify unknown movie/episode identities.
  • Do not expose the application directly to the open internet.
  • Do not run multiple organisers against the same live media in parallel.
  • Review permissions and mounts before any install or upgrade.
  • Do not assume AI suggestions or connected metadata are guaranteed correct.

Frequently asked questions

Is Namerr free?

The intended community offering is free to use, with voluntary contributions to support maintenance. Public distribution terms will be published with the public release.

Can I download it right now?

Not from this public website yet. The verified public package is still in preparation. The download page will only present real, tested public links.

Does Namerr need the cloud?

Its core naming and review workflows are local. Some optional metadata integrations use network access. Future AI features will distinguish local-only and cloud-assisted modes.

Does Namerr automatically delete duplicates?

No general-purpose automatic duplicate deletion is advertised. Review ambiguous files carefully, and maintain independent backups.

Does it support music, books or photos today?

Not yet. Those are later modular media-library expansions on the roadmap.
