PRODUCT ROADMAP

A clearer way forward.

We're building Namerr in deliberate increments: protect media first, improve the review experience next, and expand only when the foundations are reliable.

Roadmap ≠ release promise.

This page describes direction, not guaranteed dates or shipped functionality. The application’s own engineering roadmap and release acceptance remain the source of truth.

Current foundation

Movie & TV core

The existing Namerr 2.0.48 development baseline includes movie and TV library organisation, configurable naming profiles, review decisions, stored evidence, selective operations and conservative recovery safeguards.

Planned

Better guided review

Make uncertain files easier to understand and correct: clearer item-level guidance, saved decisions, review context and less needless rescanning.

Planned

AI-assisted intelligence

Explain recommendations using verifiable evidence, help identify difficult specials and extras, and make library health easier to understand. Proposed providers include Ollama, OpenAI, Claude and Grok, subject to capability, privacy and explicit approval gates.

Planned

Jellyfin support

Extend existing media integration patterns to Jellyfin, with read-only capability discovery before any separately approved write or notification workflow.

After core

More media types

A modular foundation for music and MP3 collections, ebooks and comics, audiobooks and podcasts, then photos and home videos. Every new format needs its own metadata, sidecar, identity and recovery checks.

After core

Storage insights

Understand growing libraries with read-only reports and candidate recommendations. Protected backups, snapshots and system files must never be silently cleaned up.

Public launch gate

Community distribution

Verified public releases, a clear licence, reproducible installation, safe upgrade instructions, accessible documentation and a practical support channel. This website is one part of that work.

Help shape what's next

Feedback from real libraries is more useful than a long list of hypothetical features. The project intends to make community contributions and bug reporting straightforward when public distribution opens.
