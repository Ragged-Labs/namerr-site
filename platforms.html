A CONSISTENT SAFETY MODEL

Review first.
Move with confidence.

The same safety principles guide each planned edition, while file operations must still meet platform-specific tests.

  1. 01

    Discover

    Scan selected library locations and identify naming or metadata issues without changing files.

  2. 02

    Review

    Show proposed naming and location changes, explain uncertainty and require an explicit decision.

  3. 03

    Apply safely

    Enable writes only on validated storage, with logging, recovery and Undo/rollback checks.

On a desktop volume whose permissions, move behaviour or recovery haven't been validated, Namerr should remain in scan-and-preview mode. No public release date is announced.
