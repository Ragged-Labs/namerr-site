# Security policy — Namerr website

This is the static website for **Namerr** by RaggedLabs Media. The public site is a Coming Soon page, not an application distribution portal.

## Report vulnerabilities privately

Email **contact@raggedlabs.media** with the subject line **[Namerr Website Security]**.

Please include the affected URL, a reproducible description, severity/impact and contact details. Avoid reporting exploitable security details in public GitHub issues.

## Supported scope

Website HTML, CSS, link destinations and repository security are maintained during prelaunch. The Namerr application itself is private development software and has **no announced public supported release**.

## Security principles

- No secrets, credentials, cryptocurrency signing keys or wallet recovery phrases in Git history.
- No customer analytics, payment embeds or unnecessary third-party scripts on the prelaunch website.
- Download and donation targets must be independently verified before publication.
- Production `main` should be protected by a GitHub ruleset before accepting outside contributions.

For general enquiries, visit the site or email **contact@raggedlabs.media**.
