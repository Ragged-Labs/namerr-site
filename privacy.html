WEBSITE PRIVACY

Less tracking.
More trust.

Privacy information for this public website, not the separate Namerr application.

Website data

This website is built from static HTML, CSS and a small local navigation script. We do not currently include analytics scripts, advertising pixels, marketing trackers, user accounts, forms or first-party tracking cookies.

Hosting is provided by GitHub Pages when publication is enabled. GitHub may process technical requests and logs according to its own terms and privacy practices.

External links

Links to GitHub and future donation or download providers take you to separate services, which have their own privacy policies. Donation links are not yet configured. We do not process payments on this site.

Media library privacy

Using this website does not access or inspect your media library. Namerr itself runs in your own environment and may use network services only when configured. Its application privacy and provider-access documentation will accompany public distribution.

Changes

This page will be updated when site functionality materially changes, especially if analytics, community forms, support platforms or payment links are added.
